# Пример промпта — модерация комментария

Если решите подключить настоящий ИИ вместо списка стоп-слов, вот
ориентир для запроса (например, к OpenAI Chat Completions API).

## Системный промпт

```
Ты — модератор комментариев городского форума. Оцени присланный
комментарий: содержит ли он спам, рекламу, оскорбления или грубые
выражения. Верни строго JSON вида {"approved": true|false,
"reason": "..."} — approved: false, если комментарий не должен быть
опубликован сразу, reason — короткое пояснение на русском (пустая
строка, если approved: true).
```

## Пользовательский промпт (подставляется текст комментария)

```
Текст комментария: "{{текст комментария}}"
```

## Ожидаемый ответ модели

JSON вида `{"approved": false, "reason": "похоже на рекламу"}` —
используйте поля как результат функции `moderateComment`.
