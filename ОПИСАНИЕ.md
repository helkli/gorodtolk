# «ГородТолк» — краткое описание работы проекта

**Что это.** Статический форум-страница без сервера и без сборки:
`index.html` + `style.css` + `script.js`, открывается двойным щелчком
(`file://`) или через `python3 -m http.server`. Данные хранятся в
`localStorage` браузера.

## Основной поток

1. Пользователь вводит имя и текст и нажимает «Опубликовать».
2. Кнопка блокируется («Проверяем…»), текст нормализуется и уходит в
   `moderateComment()` — ИИ-функция проверки комментария.
3. Проверка идёт по 12 локальным правилам (R01–R12): ссылки и
   контакты, словари грубого и рекламного лексикона, капс, флуд,
   повторы, длина. Каждое срабатывание даёт баллы; **порог — 100**
   (`MODERATION_THRESHOLD`).
4. **Набрал ≥ 100 → `approved: false`**: комментарий сохраняется, но в
   общую ленту не показывается — виден только модератору, с красной
   рамкой и меткой «На проверке модератора: <причина>». Отправитель
   видит плашку «Комментарий отправлен на проверку модератора и пока
   не виден всем».
5. **Не набрал → `approved: true`**: публикуется сразу, зелёная
   плашка «Комментарий опубликован.» гаснет через 5 секунд.
6. Сбой проверки комментарий не теряет: он сохраняется с причиной
   «не удалось проверить автоматически» и попадает в очередь.

## Режим модератора

Чекбокс «Режим модератора» над лентой переключает вид без
перезагрузки: очередь отклонённых комментариев с причинами и счётчик
«На проверке: N» в заголовке; при пустой очереди — заглушка «Очередь
пуста». Состояние переключателя сохраняется и переживает F5.
Кнопок одобрения/отклонения нет — модератор правит очередь вручную
(решение заказчика, ТЗ п. 19).

Только в режиме модератора видна кнопка **«Очистить ленту»**: после
подтверждения («Удалить все комментарии? Это действие нельзя
отменить.») удаляет все комментарии из `localStorage`; режим
модератора и другие данные при этом не сбрасываются, публиковать
заново можно сразу.

## Старые записи

Комментарии без поля `approved` (из прежних версий) мигрируют при
загрузке: показываются в общей ленте без меток и в очередь не попадают.

## Качество (приёмочный прогон, 45 примеров, T1–T18)

| Метрика | Норма ТЗ | Факт |
|---|---|---|
| Recall (спам пойман) | ≥ 90 % | 100 % (15/15) |
| Ложные срабатывания | ≤ 10 % | 0 % (0/30) |
| Время проверки | < 20 мс | < 1 мс |
| Ошибки / сетевые запросы | 0 | 0 |

Работает полностью офлайн: ключи API не нужны, сеть не используется
(ТЗ SEC-01/SEC-02 — ключ в браузере небезопасен, внешний ИИ через
серверный прокси возможен отдельным этапом).

## Настройка

Всё — в начале `script.js`, без правки логики:

- `MODERATION_MODE` — `"rules"` (по умолчанию);
- `MODERATION_THRESHOLD` — порог строгости (100);
- `ALLOWED_DOMAINS` — белый список ссылок;
- `MODERATION_DICTIONARIES` — словари («*» в конце слова = совпадение
  по началу, иначе — слово целиком);
- таблица `MODERATION_RULES` — правила R01–R12 и их веса.

## Документы

- `ТЗ_МОДЕРАЦИЯ_КОММЕНТАРИЕВ.md` — договорное ТЗ (не редактировалось);
- `ОТКЛОНЕНИЯ_ОТ_ТЗ.md` — 4 согласованных отклонения;
- `ЗАПУСК.md` — инструкция по запуску.
