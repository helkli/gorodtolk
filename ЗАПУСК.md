# Запуск проекта «ГородТолк»

Форум обсуждений — без сервера и без сборки. ИИ-функция модерации
комментариев реализована локальными правилами (ТЗ
`ТЗ_МОДЕРАЦИЯ_КОММЕНТАРИЕВ.md`, v1.1; отклонения — в
`ОТКЛОНЕНИЯ_ОТ_ТЗ.md`).

## Как запустить

Откройте `index.html` двойным щелчком (или File → Open в браузере).
Если браузер ругается на `localStorage` при открытии файла напрямую
(`file://`), запустите локальный сервер:

```bash
python3 -m http.server 8000
```

Оба способа проверены: страница работает и по `file://`, и через
`http.server`.

## Что реализовано

- **Проверка перед публикацией** — `moderateComment(text)` в
  `script.js`: 12 правил R01–R12 (ссылки и контакты, словари грубых
  выражений и рекламы, капс, флуд, повторы, длина), порог
  `MODERATION_THRESHOLD = 100` баллов — набрал больше или равно → на
  проверку.
- **Отклонённый комментарий не показывается в общей ленте** (решение
  ТЗ, п. 19): он сохраняется со статусом «на проверке», виден только
  модератору — с меткой «На проверке модератора: <причина>» и красной
  рамкой (стили `.comment-flagged`/`.flag-label` в `style.css`).
- **Режим модератора** — чекбокс над лентой и счётчик «На проверке: N»
  в заголовке; очередь показывает отклонённые с причинами, пустая
  очередь — заглушка «Очередь пуста». Состояние переключателя
  переживает перезагрузку страницы (F5). Только в этом режиме видна
  кнопка **«Очистить ленту»** — с подтверждением, удаляет все
  комментарии (см. `ОТКЛОНЕНИЯ_ОТ_ТЗ.md`, ОТК-05).
- **Уведомления:** «Комментарий отправлен на проверку модератора и
  пока не виден всем»; при одобрении — зелёная плашка «Комментарий
  опубликован.» (сама исчезает через 5 с); при ошибке проверки
  комментарий всё равно сохраняется с честной причиной.
- **Старые комментарии** (из прежних версий, без поля `approved`)
  показываются без меток и в очередь не попадают — миграция при
  загрузке.

## Настройка

Всё — в начале `script.js`, без правки логики:

- `MODERATION_MODE` — `"rules"` (по умолчанию, работает офлайн);
- `MODERATION_THRESHOLD` — порог строгости (100);
- `ALLOWED_DOMAINS` — белый список ссылок (википедия, гос sites, ТАСС…);
- `MODERATION_DICTIONARIES` — словари (грубое, рекламное, контактное);
  «*» в конце слова = совпадение по началу, иначе — слово целиком;
- таблица `MODERATION_RULES` — правила R01–R12, вес каждого.

## Проверка качества (ТЗ, разд. 15)

По приёмочному прогону (T1–T18, набор 45 примеров):

| Метрика | Норма | Факт |
|---|---|---|
| Найден спам (recall) | ≥ 90 % | 100 % (15/15) |
| Ложные срабатывания | ≤ 10 % | 0 % (0/30) |
| Время проверки | < 20 мс | < 1 мс |
| Ошибки / сетевые запросы | 0 | 0 |

Повторить вручную: отправьте обычный комментарий (публикуется
сразу), затем `Заработок без вложений, пишите http://site.ru/promo`
(исчезает из ленты, появляется в очереди модератора после включения
переключателя).

## Внешний ИИ-API — не включён

`.env.example` и `PROMPT_EXAMPLE.md` — ориентиры для варианта с
внешним API. В браузер ключ не встраивается (ТЗ SEC-01, SEC-02: ключ
виден любому посетителю), поэтому режим `"api"` требует серверного
прокси и реализуется отдельным этапом.

## Файлы

- `index.html` — разметка: форма, лента, переключатель и счётчик
- `style.css` — стили, включая метки модерации и уведомления
- `script.js` — логика: конфиг, правила, `moderateComment`, отрисовка
- `ТЗ_МОДЕРАЦИЯ_КОММЕНТАРИЕВ.md` — договорное ТЗ (не редактировалось)
- `ОТКЛОНЕНИЯ_ОТ_ТЗ.md` — согласованные отклонения от ТЗ (4 пункта)
- `ОПИСАНИЕ.md` — краткое описание работы проекта
- `.env.example`, `PROMPT_EXAMPLE.md` — материал для этапа с API
